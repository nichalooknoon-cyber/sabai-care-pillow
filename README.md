# SabaiCare Pillow

Bilingual (Thai/English) senior-friendly static web app for a health-pillow shop, open 08:00–20:00.

## Features
- TH/EN language switch
- Symptom/need-based pillow recommendation
- 8 sample pillow products and sample prices
- Senior-friendly large text and controls
- Health tips, contact section, medical disclaimer
- No backend and no personal/health data transmission

## GitHub Pages
This project is static and can be published directly from the repository root on the `main` branch.

> Product names, prices, and contact links are placeholders and should be replaced before commercial use.
